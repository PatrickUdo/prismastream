# PrismaStream voor Apple TV (tvOS)

Capacitor draait niet op tvOS: Apple TV heeft geen WKWebView. Daarom is de Apple TV-app een **native SwiftUI-app** die de **TypeScript-kern deelt** met de web-, iOS- en Android-app. De samenvoeg-engine, IPTV-parsers, zoekfunctie en voorbeelddata bestaan dus maar één keer.

```
src/lib/{merge,providers,sample,search,...}  (TypeScript, gedeeld)
        │  vite build --config vite.core.config.ts
        ▼
tvos/PrismaStream/Resources/prisma-core.js   (IIFE, global `PrismaCore`, zonder DOM en zonder netwerk)
        │  JavaScriptCore (JSContext)
        ▼
tvos/PrismaStream/Core/CoreEngine.swift      (Swift-bridge: JSON in en JSON uit)
        │
SwiftUI-schermen · AVPlayer · URLSession · Keychain
```

## Verdeling van verantwoordelijkheden

| Wat                                                                                 | Waar                                                                   |
| ----------------------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| Netwerk (Xtream API, M3U-download, XMLTV-download, gzip)                            | Swift (`URLSession`, `Compression`)                                    |
| Parsen en mappen (M3U-tekst, Xtream-JSON, XMLTV-tekst)                              | JS-kern                                                                |
| Samenvoegen (talen, dubbelen, series, zenders), variantkeuze, weergavetitel, zoeken | JS-kern                                                                |
| Opslag van catalogus-cache, profielen, favorieten, voortgang                        | Swift (bestanden in Application Support / `UserDefaults`)              |
| Wachtwoorden                                                                        | Swift Keychain, nooit in JS en nooit in logs                           |
| Afspelen                                                                            | `AVPlayerViewController` (native HLS, audio- en ondertitelsporen, PiP) |

## Contract van `PrismaCore` (alle argumenten en returnwaarden zijn JSON-strings)

De JS-kern draait in een kale `JSContext`: er zijn geen `window`, `document`, `fetch`, `indexedDB`, `localStorage`, `crypto.subtle` of `TextDecoder`, en mogelijk geen `setTimeout` (Swift levert die via een shim). De bundel bevat zelf de polyfills die hij nodig heeft (bijv. `structuredClone`) en mag geen van deze globals aanspreken bij het laden.

| Functie                                               | Input                                                                                                                                                                                                                           | Output                                                                                                                                             |
| ----------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| `PrismaCore.version()`                                | –                                                                                                                                                                                                                               | `"x.y.z"` (plain string)                                                                                                                           |
| `PrismaCore.sampleCatalogs()`                         | –                                                                                                                                                                                                                               | `RawCatalog[]` (de 3 demobronnen)                                                                                                                  |
| `PrismaCore.sampleSources()`                          | –                                                                                                                                                                                                                               | `{ id, name, type: 'sample' }[]`                                                                                                                   |
| `PrismaCore.buildCatalog(raws, opts)`                 | `RawCatalog[]`, `{ sourceNames?: Record<string,string>, preferLang?: string }`                                                                                                                                                  | `Catalog`                                                                                                                                          |
| `PrismaCore.mergeSeasons(title, rawEpisodesBySource)` | `Title`, `{ sourceId, providerId, langs, episodes: RawEpisode[] }[]`                                                                                                                                                            | `Title` (met `seasons`)                                                                                                                            |
| `PrismaCore.parseM3U(text, sourceId)`                 | M3U-tekst, bron-id                                                                                                                                                                                                              | `{ catalog: RawCatalog, epgUrl?: string }`                                                                                                         |
| `PrismaCore.xtreamMap(kind, json, ctx)`               | `kind`: `'vod' \| 'series' \| 'live' \| 'seriesInfo' \| 'vodCategories' \| 'seriesCategories' \| 'liveCategories' \| 'account'`; de ruwe API-JSON; `ctx`: `{ sourceId, serverUrl, username, password, categories?, seriesId? }` | `RawMovie[]`, `RawSeries[]`, `RawChannel[]`, `RawEpisode[]`, categoriemap of accountinfo                                                           |
| `PrismaCore.parseXmltv(text, opts)`                   | XMLTV-tekst, `{ windowStart?, windowEnd?, channelIds?: string[] }`                                                                                                                                                              | `EpgProgramme[]`                                                                                                                                   |
| `PrismaCore.pickVariant(variants, prefs, title?)`     | `StreamVariant[]`, `{ audioLangs, subtitleLangs, subtitlesOn }`, optioneel `Title`                                                                                                                                              | `StreamVariant \| null`                                                                                                                            |
| `PrismaCore.groupVariantsByLanguage(variants)`        | `StreamVariant[]`                                                                                                                                                                                                               | `{ lang, variants }[]`                                                                                                                             |
| `PrismaCore.summarizeLanguages(title)`                | `Title`                                                                                                                                                                                                                         | `"NL · EN · DE +4"` (plain string)                                                                                                                 |
| `PrismaCore.displayTitle(title, prefs)`               | `Title`, `{ uiLang, audioLangs }`                                                                                                                                                                                               | plain string                                                                                                                                       |
| `PrismaCore.searchIndex(catalog)`                     | `Catalog`                                                                                                                                                                                                                       | `true` (bouwt de index in de context)                                                                                                              |
| `PrismaCore.search(query, limit?)`                    | zoektekst                                                                                                                                                                                                                       | `{ movies: Title[], series: Title[], people: {name, titles}[], channels: Channel[], genres: string[] }` (alleen ids plus wat nodig is om te tonen) |
| `PrismaCore.recommend(catalog, history, favorites)`   | `Catalog` (of index), ids                                                                                                                                                                                                       | `string[]` (titel-ids)                                                                                                                             |

**Foutafhandeling:** bij een fout gooit een functie een `Error`. Swift vangt die via `context.exceptionHandler` en toont een nette foutmelding.

**Types:** de JSON-vormen zijn exact die van `src/lib/types.ts`. Swift spiegelt ze met `Codable`-structs in `tvos/PrismaStream/Core/Models.swift`.

## Build

- Kern: `npm run build:core`, wat `tvos/PrismaStream/Resources/prisma-core.js` schrijft.
- App: `tvos/project.yml` (XcodeGen) → `cd tvos && xcodegen generate`, wat `PrismaStream.xcodeproj` maakt. Bouwen met `xcodebuild -scheme PrismaStreamTV -sdk appletvsimulator`.
- Bundle-id: `nl.tuwi.prismastream.tv`, minimaal tvOS 17.

## Kern: status

- **Bouwen:** `npm run build:core` (Vite library-build, `vite.core.config.ts`): `src/core/index.ts` wordt één geminificeerde IIFE (`var PrismaCore = …`, target es2020, zonder imports of chunks) in `tvos/PrismaStream/Resources/prisma-core.js`. Bouw opnieuw na elke wijziging in `src/lib/{merge,providers,sample,search}`.
- **Grootte:** ca. 147 KB (55 KB gzip), inclusief voorbeelddata en saxes.
- **Kale context:** de bundel spreekt bij het laden en in de API geen `window`, `document`, `fetch`, `URL`, `TextDecoder`, `crypto`, timers of `console` aan, en bevat geen Svelte. `src/core/polyfills.ts` vult alleen `globalThis`, een stille `console` en `structuredClone` (via JSON) aan als die ontbreken. Alles is synchroon; Swift hoeft geen `setTimeout` of andere globals te injecteren.
- **Tests:** `src/core/core.test.ts` bouwt de bundel in het geheugen (Vite-API) en draait hem in een kale `node:vm`-context. Daarnaast is hij met de `jsc`-shell van macOS getest.
- **Argumenten:** JSON-strings; een al geparst object mag ook. Optionele argumenten mogen weggelaten worden of `null` zijn.

**Afwijkingen en aanvullingen op het contract** (alle aanvullend; de vormen uit de tabel blijven geldig):

| Functie                                          | Aanvulling                                                                                                                                                                                                                                                                                                                        |
| ------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `version()`                                      | De API-versie van de kern (`1.0.0`), niet de app-versie.                                                                                                                                                                                                                                                                          |
| `buildCatalog(raws, opts)`                       | `opts` accepteert ook `sourceLangs` en `now`. `sourceNames` wordt aangevuld met de namen van de demobronnen. Onthoudt raws en catalogus in de context (voor `mergeSeasons`, `searchIndex()` en `recommend(null, …)`).                                                                                                             |
| `mergeSeasons(title, sources, opts?)`            | Elk bronitem mag ook `info` hebben (uit `xtreamMap('seriesDetails')`) om ontbrekende metadata aan te vullen, net als in de web-store. Optioneel `subtitleLangs`, `quality` en `seriesTitle` als de ruwe serie niet in de laatste `buildCatalog` zat. `opts`: `{ preferLang? }`. Werkt ook de titel in de onthouden catalogus bij. |
| `parseM3U(text, sourceId)`                       | Geeft ook `epgUrls` (alle) en `entryCount`. Gooit een fout bij een playlist zonder items (zoals de web-app). `catalog.epg` is `[]`.                                                                                                                                                                                               |
| `xtreamMap(kind, json, ctx)`                     | Extra kind `'seriesDetails'` → `{ info: Partial<RawSeries>, episodes: RawEpisode[] }`. `ctx.categories` is de map uit een `*Categories`-call of de ruwe categorielijst. `'account'` gooit `HttpError` (`name: 'HttpError'`) bij auth 0, verlopen of geen Xtream-server.                                                           |
| `pickVariant(variants, prefs, title?)`           | `prefs` mag ook `lastGoodSourceId` en `failedSourceIds` bevatten. Geen variant → `"null"`.                                                                                                                                                                                                                                        |
| `groupVariantsByLanguage(variants, prefs?)`      | Optioneel `{ audioLangs }` voor de volgorde.                                                                                                                                                                                                                                                                                      |
| `summarizeLanguages(title, prefs?, max?)`        | Optioneel `{ audioLangs }` (standaard `['nl']`) en `max` (standaard 3).                                                                                                                                                                                                                                                           |
| `searchIndex(catalog?)`                          | Zonder argument wordt de laatst gebouwde catalogus gebruikt (scheelt een grote JSON-overdracht).                                                                                                                                                                                                                                  |
| `search(query, limit?)`                          | Titels zijn volledige `Title`-objecten **zonder `seasons`**; `people[].titles` idem, plus `profileUrl?`. Extra velden: `query`, `total` en `akas` (`titleId → alternatieve titel die matchte`). `limit` begrenst films, series en zenders (standaard 48/48/24); personen max 12, genres max 8.                                    |
| `recommend(catalog, history, favorites, limit?)` | `catalog` mag `null` zijn (laatst gebouwde). `history` is `HistoryEntry[]` of een lijst titel-ids (recentste eerst). Standaard 24 ids.                                                                                                                                                                                            |

**Gedeelde refactors (gedragsneutraal voor de web-app):** `#lib/providers/xtream-map.ts` (pure Xtream-mappers, opnieuw geëxporteerd door `xtream.ts`), `#lib/providers/errors.ts` (`HttpError`, opnieuw geëxporteerd door `http.ts`), `splitUrl`/`splitUrlPure` in `util.ts` (gebruikt `URL` als die bestaat), `parseXmltvText`/`createXmltvCollector` in `xmltv.ts`, en `#lib/merge/display.ts` (`displayTitleFor`, `localizedTitle`, …; `components/titles.ts` exporteert die opnieuw).
